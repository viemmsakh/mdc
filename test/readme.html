Markdown to HTML Converter

A CLI Tool written in Rust that converts Markdown files into styled HTML or PDF documents. Features a live-reloading mode "--live" with a built-in web server for real-time previews.

Installation

  1. Clone the repository:

    git clone https://github.com/viemmsakh/mdc.git
    cd mdc

  2. Build with Cargo

    cargo build --release

Usage

Run the progam without arguments to see the help screen

Basic Conversion Outputs a raw HTML snippet to the terminal:

./mdc --input README.md

Save to File with Styling Wraps the content in a full HTML document and saves it to a specific path, infers exension if not given:

./mdc --input README.md --output test/readme --html

Save to PDF Generates a PDF and saves it to a specific path, infers exension if not given:

./mdc --input README.md --output test/readme --pdf

Live Preview Starts a local server and watches for file changes. Everytime you save your markdown file, the browsers at http://0.0.0.0:3000 will refresh instantly:

./mdc --input README.md --live

Command Line Arguments

FlagShortDescription
--input-iRequired. Path to the input .md file.
--output-oPath to the output file.
--htmlWraps the output in a styled HTML boilerplate.
--pdfOutputs markdown to PDF.
--live-lWatches input for changes and displays updates live in browser.
--port-pPort to serve the live preview on (default: 3000).
--help-hDisplays help information.
--version-VDisplays version information.
